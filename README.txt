MY EARNINGS TRACKER

Files:
- index.html: app
- manifest.webmanifest and sw.js: install/offline support when hosted

QUICK USE:
1. Open index.html in a browser to use the tracker.
2. For a proper installable Android app icon and offline support, publish these three files to an HTTPS static host (for example GitHub Pages or Netlify).
3. Open the HTTPS website in Chrome on your phone, tap the three-dot menu, then choose Install app or Add to Home screen.

The app stores records locally in the browser on that phone. Export the JSON backup regularly. It does not sync between devices.

Dates and wages are preconfigured: 17 Nov 2026 to 21 Feb 2027, US$5 per worked day. The payment schedule assumes payment one day after each seven-day work period; confirm the actual arrangement with your employer.
